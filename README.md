# Undangan Pernikahan Digital

Website undangan pernikahan modern dengan Next.js 14, Tailwind CSS, dan Framer Motion.

## Fitur
- ✅ Hero section dengan animasi halus
- ✅ Countdown timer real-time
- ✅ Detail lokasi acara
- ✅ Form RSVP modern
- ✅ AI Wish Formatter (Gemini API)
- ✅ Fully responsive design
- ✅ Premium typography
- ✅ Smooth animations

## Tech Stack
- Next.js 14 (App Router)
- Tailwind CSS
- Framer Motion
- Google Gemini AI
- TypeScript

## Deployment
1. Fork repository ini
2. Deploy ke Vercel dengan 1 klik
3. Tambahkan `NEXT_PUBLIC_GEMINI_API_KEY` di Vercel Environment Variables

## Customization
1. Ganti nama pasangan di `components/Hero.tsx`
2. Update tanggal pernikahan di `components/Countdown.tsx`
3. Sesuaikan lokasi di `components/Location.tsx`
4. Tambahkan Gemini API key di `.env.local`
